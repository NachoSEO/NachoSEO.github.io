## The context

I wanted to keep working on my projects away from the laptop. Before Anthropic shipped its own remote control for Claude Code, I built the interface myself: Telegram as a mobile front end driving a real Claude Code agent on my machine.

## The system

- **A real agent, not a chatbot**: the bot exposes the agent's full tool access — bash, file I/O, code editing and web fetching — from anywhere.
- **Stack**: TypeScript, Grammy and the Claude Agent SDK. Published as open source under the MIT license.
- **Voice layer**: send a voice note, it's transcribed with Whisper and fed to the agent; the response comes back as a spoken Telegram voice note. Building that layer taught me firsthand where TTS quality and latency make or break a conversational interface.

## The result

The first signal it worked: I use it daily. The second was external: **147 stars and 55 forks on GitHub**, from people who had the same problem and chose my solution over waiting for the official one.

The code lives at [github.com/NachoSEO/claudegram](https://github.com/NachoSEO/claudegram).
